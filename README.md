# VoltFlow: Online Electric Car Charging Station System

React-based EV Charging Station Reservation and Management System | CENG 475 Advanced Web Programming with React, Project 4.

VoltFlow lets customers find charging stations, check free time slots, reserve a charger, follow a (simulated) charging session and read in-app notifications. Administrators manage stations, chargers, time slots, prices and reservations and read usage statistics.

> **Honest status.** This repository is a **working baseline**, not the finished product. Login, role-based access, the database, every page, all shared components and the read-only parts of the API work today. The main write features (register, create and cancel reservations, start and stop charging, admin create/edit/delete) are deliberately left to the three developer branches. Every unfinished screen shows a yellow **Starter screen** notice and every unfinished API call answers `501 NOT_IMPLEMENTED` with the name of the owner. Nothing pretends to work when it does not. See [docs/TASK_DISTRIBUTION.md](docs/TASK_DISTRIBUTION.md).

## Important notes

* **Charging is simulated.** There is no car, charger hardware or payment provider. The UI always shows a "Simulation" label.
* **Notifications are in-app only.** They are stored in the database and shown in the notification centre. No e-mail, SMS or push message is ever sent.
* Demo data is generated by `npm run db:reset`. Seeded dates are relative to the moment the database is created, so run `npm run db:reset` before a demo if the database is older than a day.

## Quick start

Requires **Node.js 22 LTS** (22.12 or newer, see `.nvmrc`) and npm 10+. No other software, no Docker, no database server.

```bash
npm ci            # or: npm install
npm run dev       # API on http://localhost:3001, web app on http://localhost:5173
```

Open http://localhost:5173. The database file `data/voltflow.db` is created and seeded automatically on first start.

| Command | What it does |
| --- | --- |
| `npm run dev` | Starts the API (auto restart) and the Vite dev server together |
| `npm run build` | Production build of the web app into `dist/` |
| `npm start` | Serves API and built web app on http://localhost:3001 (run `npm run build` first) |
| `npm test` | Runs all tests with Node's built-in test runner |
| `npm run db:reset` | Deletes the database and creates a fresh seeded one |
| `npm run check:ownership` | Checks that your branch only changes files you own |

Detailed setup: [macOS](docs/SETUP_MACOS.md) and [Windows (PowerShell)](docs/SETUP_WINDOWS.md).

## Technology

| Layer | Choice |
| --- | --- |
| Front end | React 19, React Router 7, Context API, plain CSS with design tokens, vanilla JavaScript utilities, Vite |
| Back end | Node.js, Express 5 |
| Database | SQLite through `sql.js` (WebAssembly, no native build step), persisted to `data/voltflow.db` with atomic file writes |
| Security | bcrypt password hashing (`bcryptjs`), signed JWT, parameterised SQL only, server-side validation, role checks on every admin route |
| Tests | Node built-in `node --test` (no test framework dependency) |

No TypeScript, Tailwind, Docker or Firebase are used.

```
    main.jsx App.jsx
    routes/          registry.jsx (all routes), RouteShell.jsx (guards)

    context/ hooks/ lib/ styles/
  scripts/           dev runner, db reset, ownership check
  docs/              all project documents
  .github/           pull request template and CI workflow
```
